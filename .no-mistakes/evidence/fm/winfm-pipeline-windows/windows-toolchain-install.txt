Windows install arms for ShellCheck + actionlint, exercised end-to-end.

Host is WSL2 Linux, so `uname` is stubbed to what Git Bash reports on a
windows-latest runner (MINGW64_NT-10.0-26200 / x86_64) and RUNNER_TEMP is
spelled the way GitHub spells it there (a path holding backslashes). Every
other step is real: the real GitHub release asset is downloaded, the real
sha256 pin is verified, real unzip extracts it, and the installed .exe is
really executed (WSL2 binfmt runs PE binaries natively).

$ uname -s && uname -m
MINGW64_NT-10.0-26200
x86_64
